# PeopleCore Logo Kit

Transparent-background logo assets for the PeopleCore HCM project.

## Variants

Each variant is provided as SVG and PNG:

- `peoplecore-logo-light-horizontal-long`
- `peoplecore-logo-light-horizontal-short`
- `peoplecore-logo-light-vertical-long`
- `peoplecore-logo-light-vertical-short`
- `peoplecore-logo-light-mark-only`
- `peoplecore-logo-dark-horizontal-long`
- `peoplecore-logo-dark-horizontal-short`
- `peoplecore-logo-dark-vertical-long`
- `peoplecore-logo-dark-vertical-short`
- `peoplecore-logo-dark-mark-only`

Additional app icons:

- `peoplecore-icon-32.png`
- `peoplecore-icon-64.png`
- `peoplecore-icon-180.png`
- `peoplecore-icon-512.png`

## Usage Rules

- Use `light` logos on light backgrounds.
- Use `dark` logos on dark backgrounds.
- Use horizontal long for marketing header/footer.
- Use horizontal short for app top nav.
- Use vertical long for centered auth/empty-state branding.
- Use vertical short or mark-only for favicon, collapsed sidebar, and mobile app icon.

## Design Tokens Used

The logo colors are aligned with the PeopleCore token system:

- Primary light: `#138a5b`
- Primary dark: `#34c987`
- Light foreground: `#10201a`
- Dark foreground: `#edf7f2`
- Accent: `#2f80ed` / `#63a4ff`

All files have transparent backgrounds.
